# 工作交接

## 怎么做

1. 读取当前规格、任务、工作树和最近的检查结果，分清已经完成、正在进行、尚未确认和被什么阻塞。
2. 记录目标、已经做出的决定、改过的文件、运行过的命令及结果、未提交改动、下一步和继续工作时应该先打开的文件。已有内容直接链接，不复制大段正文。
3. 默认写入 `.scratch/handoffs/YYYYMMDD-HHMM-<slug>.md`；用户指定路径时按用户要求。敏感信息只写保存位置和脱敏说明，不写原值。
4. 完成前检查一个不了解前情的人能否据此继续，并明确列出仍需用户决定的问题。

## 限制

交接文件只记录状态，不等于提交、发布或通知他人。不要自行移动、清理或归档文件，也不要改变任务状态；没有运行的命令不能写成已经通过。
