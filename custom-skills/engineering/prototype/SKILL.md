# 原型验证

## 怎么做

1. 先写清要回答的一个问题、什么结果算成功，以及这次明确不验证什么。
2. 在 `.scratch/prototypes/<slug>/` 或用户指定的临时目录中实现。默认不用真实凭证、生产数据和长期保存的数据，也不写外部系统。
3. 保留最简单的运行命令，显示关键结果和失败情况，并实际运行一次。记下使用环境、已知限制，以及它与正式实现的差别。
4. 在答复中说明结论、限制和仍需确认的问题。已有 PRD 时更新原型验证的结果；形成了难以撤销且以后需要解释的决定时写 ADR。标明这是一份原型；只清理本次创建且用户不需要保留的临时文件。保存、更新或清理文件后，在答复中说明实际变化。

## 限制

不要自行创建分支、提交、部署或把原型接入正式代码。确实需要真实数据或外部写入时，先说明用途并取得用户授权。
